# v0.1.0 — ilk test edilebilir ürün teslimi

Tarih: 2026-10-03. Public kaynak: [aserdargun/ai-scientist](https://github.com/aserdargun/ai-scientist).

Bu ilk ürün etiketi package `0.1.0` ile uyumludur. Dahili harness/konsol teknik
sürümü `0.46.0` kalır. Önceki 0.xx geliştirme numaraları bu dahili ilerlemeyi
izler; ilk ürün etiketi için harness hash'i veya doğrulanmış model imajı değiştirilmedi.

## İçerik

- Saha amacı, veri/istatistik seçimi, LSH/OPTICS/SOM hiperparametre deneyi.
- Mod toleransı, nearest neighbor normal değer tahmini, residual ve OMR grafikleri.
- Bağımsız Scorer/Referee, bütçeli deneyler, stop/terminal ayrımı ve kalıcı rapor.
- Açıkça seçilen önceki bulgularla deney hafızası; öğretmen/eğitim hazırlık taslağı.
- Kapsamı belirtilmiş kullanım/maliyet raporu ve incelenmiş değişikliklerin güvenli yayını.
- [Başlatma rehberi](../../README.md), [bilinen eksikler](../ai-scientist/122-delivery-guide.md)
  ve [uygulama/AOS entegrasyonu](../ai-scientist/123-application-integration.md).

## Doğrulama

Teslim kaynağı: **3439 passed / 49 skipped / 177 deselected**. Beş kontrol
sonrasında `uv` bulunamayan ilk ortam hatası kaydedildi; kod hashleri korunarak
PATH düzeltildi ve wheel build/import tamamlandı. Yedi kontrol exit 0.
[Makine okunur kanıt](../ai-scientist/review-evidence/release-046-delivery.json).

Gerçek CPU örneği: saha amacı → SKAB DEV → OPTICS → doğrulanmış rapor;
279,61 saniye, 12 bağımsız skor. Arayüz masaüstü/mobil okuması ve işçi cleanup
kanıtlandı. KEEP sonucu genel iyileşme veya baseline üstünlüğü anlamına gelmez.

## Açık kalanlar

Gerçek AOS/GPU birlikte çalışma, native dışlama producer/consumer, uygulamaya
özel yetkili varlık/veri eşlemesi, öğretmen eğitimi/öğrenilmiş adapter, otomatik
skill/model terfisi ve temiz makine tam kurulum kabulü sonraki aşamadadır.
49 skip ve 177 deselected kontrol başarılı kabul diye sayılmaz. Proje lisansı
henüz seçilmedi; genel CI ve veri/model lisansları ayrı iş olarak izlenir.

Mevcut hazırlanmış CachyOS profilinde çalışır. Kaynak indirmek özel veritabanı,
model ağırlığı, API anahtarı veya kurumsal SWAPP ayarı sağlamaz. Ürünün araştırma
LLM'i yereldir; varsayılan field-lab profili CPU çalışır ve model çağrısı kapalıdır.
